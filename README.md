# 철갑돌격대 — 작전명: 까마귀 사냥

코드만으로 만든 오리지널 2D 도트 런앤건 게임. 이미지·소리 파일 없이 도트는 코드로 찍고 소리는 WebAudio로 합성한다.

- 실행: `index.html` 을 브라우저로 연다(단일 파일). GitHub Pages는 저장소 루트를 그대로 배포하면 된다.
- 모바일: 가로 화면 권장. 왼쪽 = 이동·조준 스틱, 오른쪽 = 사격 / 점프 / 폭탄.
- 키보드: 방향키(이동·조준), Z 사격, X 점프, C 폭탄, P 자동 플레이.
- 녹화용 자동 플레이: 시작 화면의 "자동 플레이" 또는 `index.html?auto=1` (1920×1080 창에서 정확히 4배 확대).
- 수정: `src/` 를 고친 뒤 `node build.js` 로 `index.html` 을 다시 만든다.
